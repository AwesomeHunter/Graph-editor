# Graph Editor

A GUI application to create, edit, and visualize graphs.

## Features

- **Graph Editing**: Interactively create and move nodes, and add edges.
- **Save / Load**: Save graphs to a file and load them later.
- **Graph Visualization**: Clear and interactive visualization of the graph structure.
- **Algorithm Visualizations**: Step-by-step execution visualization for DFS, BFS, and Dijkstra.
